# Filtros Digitales

Proyecto de Procesamiento de Señales para diseñar y comparar filtros digitales FIR e IIR.

## Archivos

- `filtros_digitales.py` - Código en Python con el diseño de los filtros
- `filtros.png` - Gráfica de la señal filtrada
- `respuesta_frecuencia.png` - Respuesta en frecuencia de los filtros

## Descripción

En este proyecto se diseñaron filtros digitales pasa-bajas usando Python, comparando la respuesta de filtros FIR e IIR y analizando su comportamiento en el tiempo y en la frecuencia.

## Herramientas

- Python
- NumPy
- Matplotlib
- SciPy
